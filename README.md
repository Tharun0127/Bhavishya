# Bhavishya (IndiaCast Arena)

The live forecasting arena for India.

Time series models forecast Indian public data before it exists. Each forecast is hashed and committed to git before the outcome is published, then scored automatically as the data arrives.

This README is a stub. It is replaced in a later build step.

Prior art: live time series benchmarks already exist (see docs/PRIOR_ART.md). This project's narrower claim is prospective, hash-committed evaluation on Indian public series, with vintage-aware data loaders.
